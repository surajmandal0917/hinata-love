# Hinata Love 💖

A creative interactive web experience built with HTML, CSS and JavaScript.

## ✨ Features

- Interactive romantic experience
- Animated UI and visual effects
- Memory section with photos
- Multiple background and memory songs
- Interactive letter experience
- Responsive design for mobile and desktop

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Audio API
- CSS Animations

## 🌐 Live Demo

[View Live Website](https://hinata-love.vercel.app)

## 📁 Project Structure

- `index.html` — Main webpage
- `style.css` — Styling and animations
- `script.js` — Interactions and functionality
- `.jpg` — Memory images
- `.mp3` — Project audio files
